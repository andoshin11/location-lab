ワイヤレス接続（Android / Wi-Fi）

端末の「開発者向けオプション → ワイヤレスデバッグ」を ON にし、Mac と同じ Wi-Fi に接続してください（Android 11 以降）。

1. ペア設定（初回のみ）

「ペア設定コードによるデバイスのペア設定」に表示される IP アドレス:ポートとコードを入力します。

2. 接続

ワイヤレスデバッグ画面の「IP アドレスとポート」を入力します（ペア設定用とは別のポートです）。

端末セットアップ

APK のパスを指定するとインストールも行います。空欄なら権限付与と「仮の現在地情報アプリ」設定のみ。
